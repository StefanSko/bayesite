# Frozen fresh-recipient protocol

Status: frozen before implementation. The failure conditions in this document
must not be changed to fit implementation outcomes.

## Supplied task

The recipient receives only the published investigation link and this task:

1. Explain the question, the estimand, the effective initial model (resolved
   parameter layout and density factors, not merely declared priors), and the
   retained limitation.
2. Obtain the pinned engine, verify the bundle, and replay the named initial
   sampling recipe on the supported target.
3. Return to the earlier likelihood decision and change one scientifically
   meaningful assumption.
4. Run the alternative, describe what the new checks do and do not support,
   and publish a new snapshot with the source relationship intact.

The task does not name an alternative likelihood or prescribe a conclusion. An
inconclusive alternative is a valid outcome.

## Frozen failure conditions

The demonstration fails if any of these occurs:

- The recipient needs help that is not in the published material.
- The recipient cannot state the effective model from the saved evidence.
- Any old result is presented as current evidence for the new model.
- The original snapshot's bytes change through supported operations.
- An unsupported, failed, or incomplete operation is presented as completed.
- Provenance for the new evidence is missing from the continuation.

## Observations to record

- Supplied instructions, platform, and engine identity as published.
- Time to identify the limitation and time to complete the continuation.
- Every command, error, request for help, and any help actually supplied.
- Original and continuation snapshot IDs, plus source verification before and
  after the continuation.
- The recipient's own explanation of the effective model and limitation.
- Evidence that old results became historical immediately after the assumption
  edit, before resampling.
- The replay report and any unresolved disagreement.

## Participant

Use one person who was not involved in implementation, in a clean workspace
with no producer environment or cached author files. The retained report must
separate automated integrity results, observed handoff success, and unresolved
product limitations.
